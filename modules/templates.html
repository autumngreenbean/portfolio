My current project is the assembly of a pcb development board that hosts a FV-1 chip.

Since the FV-1 is a programmable DSP chip, technically you can modify the firmware infinitely- but not everyone wants to learn how to program an FV-1 chip ...hmmm!

I want to make an accessible development interface for building modular effect pedals. For now I will use an outside source (pedalpcb) to assemble and learn about the FV-1.
