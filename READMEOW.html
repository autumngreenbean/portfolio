# hello peepol

welcome to the media archive of digitized things liked by autumn

## about

I like looking on archive.org and other media sites like spriter's resource and modeler's resource. This site is a place for the things I find.


This collection currently has:

    - strategy guides - video game magazines - video game booklets - video game OST lyric booklets - game theory analysis - computing magazines - anime & manga magazines


I originally intended for this to be a game assets collection, but I found a trove of online media collectibles and started with a publication library first.

I will have to figure how to embed + display assets to this sometime soon. I likely will have to source and host them myself which will be a task.
