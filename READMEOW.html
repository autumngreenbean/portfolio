# hello peepol

welcome to the media archive of digitized things liked by autumn

## about

I like looking on archive.org and here is a place for things i find on it.

this collection currently has:

    - Strategy Guides - Video Game Magazines - Computing Magazines - Anime & Manga Magazines

How to Browse

Search & Filter

Use the search box to find items by description. Filter by category to view specific collections (Computing, Video Games, Internet, Anime).

Viewing Documents

PDFs display in the built-in viewer with zoom and pagination controls. Items from Archive.org open in their native viewer.

Mobile

The archive is fully responsive. On mobile devices, the sidebar and viewer adapt for comfortable reading on any screen size.

About This Collection

These documents represent snapshots of computing culture from the 1990s and early 2000s. They capture the excitement, wonder, and creativity of an era when digital media was rapidly evolving.

Each item has been carefully curated and digitized for preservation. Many are sourced from Archive.org, a nonprofit library dedicated to preserving digital and physical culture.

Technical Details

PDF Viewer

PDFs are rendered using pdf.js, providing smooth zoom, pan, and multi-page navigation. The viewer caches recently viewed documents for fast switching.

Archive Integration

Non-PDF items are embedded directly from Archive.org's collection using their native viewer, ensuring the best experience for each document type.

Responsive Design

The entire interface is built with responsive CSS Grid, adapting seamlessly from mobile phones (768px and below) to desktop displays.
